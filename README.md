# DBMS Experiments

A collection of DBMS lab experiments implemented using MySQL and SQL. This repository contains SQL scripts and experiment reports covering fundamental and advanced database concepts.

## 📌 About the Project

The purpose of this repository is to gain practical knowledge of Database Management Systems (DBMS) by implementing SQL queries, designing relational databases, managing data, and exploring advanced SQL features.

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Workbench

## 📂 Repository Contents

- `DBMS Experiment-1.pdf` – DBMS experiment report
- `Experiment_2_DBMS (1).pdf` – DBMS experiment report
- `experiment 3.sql` – SQL experiment script
- `experiment 4.sql` – SQL experiment script
- `experiment 5.sql` – SQL experiment script
- `DBMS_EXP_6.sql` – SQL experiment script

## 📚 Concepts Covered

- Database creation and table design
- DDL and DML commands
- Primary keys and foreign keys
- SQL SELECT queries and filtering
- Aggregate functions: COUNT, SUM, AVG, MIN, and MAX
- GROUP BY, HAVING, and ORDER BY
- INNER JOIN, LEFT JOIN, and SELF JOIN
- Subqueries and EXISTS
- SQL views and view updatability
- Recursive Common Table Expressions (CTEs)
- Stored procedures and error handling
- Triggers and audit logging
- Query execution plan analysis using EXPLAIN

## 🚀 How to Run the SQL Scripts

1. Install MySQL Server and MySQL Workbench.
2. Clone or download this repository.
3. Open the required `.sql` file in MySQL Workbench.
4. Connect to your MySQL server.
5. Execute the SQL statements in the correct order.
6. Check the output of the queries to verify the results.

**Note:** Some experiments may depend on tables or data created in previous experiments. Review each script before execution and run the required setup statements first.

## 🎯 Learning Outcomes

Through these experiments, I aim to develop practical skills in:

- Relational database design and implementation
- Writing basic and advanced SQL queries
- Understanding relationships between database tables
- Managing data integrity using constraints
- Automating database operations using procedures and triggers
- Understanding query execution plans and optimization concepts
